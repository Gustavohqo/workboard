# Artefatos de IA

Material de apoio para os agentes de IA que trabalham neste repositório (veja `AGENTS.md`).

- `context/` — contexto de negócio e domínio (glossário, personas, regras do produto).
- `decisions/` — ADRs: decisões de arquitetura, uma por arquivo (`NNNN-titulo.md`).
- `prompts/` — prompts reutilizáveis que geraram bons resultados.
